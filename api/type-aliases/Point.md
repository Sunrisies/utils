# 类型别名: Point

> **Point**: `object`

表示地理坐标点及其关联距离的类型

## 类型声明

### distance

> **distance**: `number`

关联的距离值（单位：米）

### lat

> **lat**: `number`

纬度坐标（-90 到 90 之间）

### lon

> **lon**: `number`

经度坐标（-180 到 180 之间）

## 备注

该类型用于存储具有经度、纬度坐标和关联距离值的点数据，
常见于地理空间计算场景
